# **App Name**: NotaKu

## Core Features:

- User Authentication: Secure login and registration system.
- Nota Creation: Ability to create and save new notas with relevant details.
- Nota Listing: View a list of created notas, sorted by date or other criteria.
- Nota Details: View detailed information for each nota.
- Nota Summarization: Use an AI tool to summarize long notas.
- Data Storage: Securely store and manage nota data in Firestore database.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for a sense of security and trust.
- Background color: Very light blue (#E8EAF6).
- Accent color: Purple (#9575CD) to add a touch of sophistication.
- Body and headline font: 'Inter', a grotesque-style sans-serif, to maintain a modern, machined, objective, neutral look
- Use simple, clear icons for nota actions (create, edit, delete, etc.).
- Clean and organized layout to enhance user experience.
- Subtle animations for transitions and feedback.
